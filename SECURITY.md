# Security policy

## Reporting a problem in Hooligans

Please report it privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability". Please do not open a public issue for a security problem.

These count as security problems:

- Hooligans sending traffic somewhere other than the app it was pointed at.
- A secret ending up in a report, a log or a prompt.
- Anything in a report that can run script or change the page.
- Anything that makes Hooligans run a command on your machine.

## Responsible use

Only point Hooligans at apps you own or have permission to test. Version 0.1 only runs against apps on your own machine.

Hooligans never promises an app is safe. It reports what its checks found and what they did not look at.
