# 0001: The name is Hooligans

Status: accepted, 2026-10-21

## Context

The first working name was Gremlin. An established company in the resilience testing space already uses it, and the npm package of that name belongs to an unrelated graph database driver. The next candidate, Hooligan, is also taken on npm, by a small utility library that has not changed since 2014.

## Decision

The project is called Hooligans: a crowd of badly behaved fake users. Each check is one hooligan, which gives the reports a voice ("3 hooligans got through your login route").

The npm package is `hooligans`, which was free when checked on 2026-10-21. The command is `hooligans`, with `hooligan` as a second name for the same command.

## Consequences

- A domain and a trademark search have not been done. Do both before any commercial use.
- Check the package name again right before the first publish.
